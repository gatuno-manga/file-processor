<task type="auto" tdd="true">
  <name>Task 1: Implement bounded worker pool in internal/pool/pool.go</name>
  <files>internal/pool/pool.go</files>
  <behavior>
    - Pool(size=2) should only allow 2 concurrent calls to processor.Process.
    - If size is 0 or negative, it should default to runtime.GOMAXPROCS(0).
    - If context is cancelled before job starts, job should not run.
    - If context is cancelled while job is running, it should return context error.
  </behavior>
  <action>
    Create a Pool struct that:
    1. Holds a channel for jobs (capacity = size).
    2. Spawns N worker goroutines on Start().
    3. Each worker listens on the jobs channel, calls processor.Process, and sends result back via a result channel provided in the job.
    4. Provides a Process(ctx, data) method that blocks until a worker picks up the job or context expires.
  </action>
  <verify>
    <automated>go test ./internal/pool/...</automated>
  </verify>
  <done>Worker pool implemented with bounded concurrency and context support.</done>
</task>
